# Security

Report Pathmine vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/EyeCrasher07/Pathmine/security/advisories/new).
Include the mod version, operating system, affected component and reproduction
steps. Keep access tokens, account files and personal world data out of public
issues and logs.

For a vulnerability that also affects an unmodified NVIDIA product, NVIDIA's
[security reporting channel](https://www.nvidia.com/en-us/security/) is available
for the upstream component. Pathmine is independently maintained.
